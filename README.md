# Scamdle

A Wordle-style website where older people practise spotting scams: three short exercises a day, each about a different kind of scam, with guides that explain how to tell real from fake.

Course project by six Erasmus students, autumn 2026. Final delivery: 15 January 2027.

## Running it locally

You need Node 22 (see `.nvmrc`) and the database URL from Vercel.

1. `npm install`
2. Copy `.env.example` to `.env` and fill in `DATABASE_URL` and `PAYLOAD_SECRET` (ask Jasper, or run `vercel env pull .env`).
3. `npm run dev`, then open http://localhost:3000 for the site and http://localhost:3000/admin for the admin panel.

Before you open a pull request, run `npm run lint`, `npm run typecheck` and `npm test`. The same checks run automatically on every pull request.

## Where things go

| Folder | What lives there | Team |
| --- | --- | --- |
| `src/app/(frontend)/` | The pages people see | Frontend |
| `src/collections/` | Payload collections: users, media, exercises | Backend |
| `src/lib/` | Shared logic such as scoring and the daily set, with a `.test.ts` file next to each module | Both |
| `src/app/(payload)/` | Admin panel and API, generated by Payload. Don't edit | — |
| `src/payload-types.ts` | Types generated from the collections. Run `npm run generate:types` after changing a collection | — |
